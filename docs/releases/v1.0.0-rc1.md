# AegisVault v1.0.0-RC1 Release Notes

## Executive Summary
AegisVault v1.0.0-RC1 is the premier enterprise secret management platform engineered for multi-tenant cloud workloads and autonomous AI agent operations. It provides hardware-grade cryptographic envelope encryption, immutable audit ledgers, fine-grained RBAC and PAM workflows, and robust disaster recovery capabilities.

---

## Key Capabilities

### 1. Cryptographic Envelope Architecture
- **4-Tier Key Hierarchy**: Cloud KMS / HSM KEK ➔ Master Encryption Key (MEK) ➔ Ephemeral 256-bit DEK ➔ AES-256-GCM Encrypted Payload.
- **Deterministic AAD**: Anti-tampering and cross-tenant replay prevention binding `org_id`, `project_id`, `environment_id`, `secret_key`, and `version`.
- **Zero-Plaintext MEK Rotation**: Re-wraps Data Encryption Keys across key versions without decrypting stored ciphertext.

### 2. Multi-Tenant Zero-Trust Isolation
- Strict organizational separation across PostgreSQL queries and caching layers.
- Anti-enumeration defense: cross-tenant probing receives deterministic `404 Not Found`.

### 3. Machine Identity & Agent Security
- **Universal Auth**: Client ID and Client Secret authentication with Argon2id/bcrypt hashing.
- **Kubernetes Auth**: Native ServiceAccount TokenReview integration.
- **OIDC / JWT Auth**: RFC 7519 validation with mandatory `alg=none` rejection and audience enforcement.

### 4. PKI & Dynamic Secret Engines
- Internal X.509 Root and Intermediate Certificate Authorities.
- Automated CRL generation and revocation distribution.
- Dynamic ephemeral credentials for PostgreSQL, MySQL, MongoDB, and Redis.

### 5. Privileged Access Management (PAM)
- Just-in-Time access requests with mandatory dual-authorization (two-man approval rule).
- Automated time-based lease expiry and emergency manual revocation.

## Deployment Requirements

- **Runtime**: Docker Engine 24.0+ & Docker Compose v2.20+
- **Database**: PostgreSQL 16+ (or Amazon RDS / Cloud SQL)
- **Cache**: Redis 7.0+ (Standalone or Redis Sentinel)
- **Reverse Proxy / TLS**: Traefik v3.0, NGINX, or Cloud Load Balancer terminating TLS 1.2/1.3.
- **Environment Variables**: See `.env.example` (ensuring `ENVIRONMENT=production`, `DEMO_MODE=false`, `COOKIE_SECURE=true`, and high-entropy `SECRET_KEY` and `MASTER_ENCRYPTION_KEY`).

---

## Upgrade & Migration Notes
- **From Pre-Release / Development**: Initial base schema migration initializes all tenant tables, audit ledgers, PAM, PKI, and KMS schemas.
- **Database Backups**: Always generate cold or point-in-time PostgreSQL backups prior to schema migration.
